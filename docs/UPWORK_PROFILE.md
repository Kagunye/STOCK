## Overview

```
I build Python tools for people who work with market data: traders, analysts and small funds who
need something that works and that they can understand.

What I can build for you:
• Trading bots & strategy automation: broker/exchange API integration, order logic, alerts
• Backtesting: test your strategy on historical data with clear performance reports
• Market data pipelines: pull, clean and store stock, ETF, crypto or fundamentals data from APIs or the web
• Dashboards: interactive Streamlit / Plotly dashboards for portfolios, signals and KPIs
• Spreadsheet automation: replace manual Excel / Google Sheets work with scripts
• AI features: add Claude/LLM-powered summaries, screening or report generation to your tools

How I work:
1. We agree on a short written scope and what "done" looks like
2. You get progress updates and working code early, not just at the end
3. Delivery includes clean, documented code and a README or short walkthrough

I use AI-assisted development to move faster, and I review and test everything before it reaches you.

I don't sell "guaranteed profit" systems or signals. I build the tools, and you own the strategy.

Send me your idea and I'll reply with a concrete plan and estimate.
```
